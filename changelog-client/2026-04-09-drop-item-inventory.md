# Клиент: выброс предмета из инвентаря (`drop_item`)

## Слои (напоминание)

- **0** — земля.
- **1** — то, что лежит на земле (как в редакторе / подбор `pickup_item`).
- **3** — слой игрока для сортировки; **выброшенный предмет** появляется **тайлом на слое 3** в **клетке игрока** (под ногами в смысле сетки).

## Сообщение WS (`service: "game"`)

- **`type`: `"drop_item"`**
- **Payload** — объект **`DropItemIntent`**:
  - **`from`** — имя слота, **как у `inventory_move`**: `armor`, `accessory_1`, `accessory_2`, `hand_main`, `hand_off`, `backpack_0`…`backpack_4`.

При успехе: из слота убирается **`item_def_id`**, на позиции игрока создаётся тайл с **`texture`** = этот id, **`layer`: 3**, **`blocks`: false** (в `state` уходит **`tile_updates`** как при `spawn_tile`).

Условия (иначе действие **тихо игнорируется**):

1. Игрок в мире.
2. В **`from`** есть непустой предмет.
3. В клетке игрока на **слое 3** ещё **нет** тайла. Если там уже что-то есть (например другой выброшенный предмет), выброс **не выполняется**, предмет **остаётся** в инвентаре — так не теряются предметы при попытке сложить два в одну клетку.

## Замечание про один тик с движением

Позиция берётся из **текущего** `GridPos` на момент обработки действия. **Перемещение** игрока применяется в **конце тика** (`postTick`). Если в одном батче сначала **`move`**, потом **`drop_item`**, выброс может произойти ещё по **старой** клетке — при необходимости отправляй **`drop_item`** отдельным тиком после хода.

## Константы в `pkg/gamekit`

- **`TypeDropItem`** = `"drop_item"`.
- **`DropItemIntent`** — структура payload (см. `wire.go`).
- **`DroppedItemTileLayer`** = **3** — слой тайла при выбросе.
