# Клиент: инвентарь в `state`, действие `inventory_move`, сохранение в character.data

## Суть

Сервер ведёт **слотовый инвентарь** игрока в ECS; в каждом `state` у объекта **`players[]`** добавлено поле **`inventory`**. Перестановка предметов между слотами — отдельное сообщение WS **`type: "inventory_move"`** (swap двух слотов).

Инвентарь **сохраняется в character.data** вместе с позицией/HP/stats (при настроенном character-service при отключении последнего WS сессии). Версия схемы **`character.data`** поднята до **`schema_version: 3`**.

## Поле `players[].inventory`

Объект с полями (все значения — **`item_def_id`** из `catalog.json`, пустая строка = пустой слот):

| Поле | Смысл |
|------|--------|
| `armor` | Броня |
| `accessory_1`, `accessory_2` | Два аксессуара |
| `hand_main`, `hand_off` | Две руки |
| `backpack` | Массив из **ровно 5** строк — слоты рюкзака (`backpack_0` … `backpack_4` в командах) |

## Действие `inventory_move`

Payload (JSON):

```json
{ "from": "hand_main", "to": "backpack_2" }
```

Имена слотов: **`armor`**, **`accessory_1`**, **`accessory_2`**, **`hand_main`**, **`hand_off`**, **`backpack_0`** … **`backpack_4`**.

Семантика: **обмен** содержимым двух слотов (как swap). Если операция невалидна (неизвестный слот, нельзя положить в рюкзак — см. ниже), сервер **молча не меняет** инвентарь (следующий `state` без изменений по инвентарю).

## Каталог: `is_storage`

У **`ItemDef`** в `catalog.json` опционально **`"is_storage": true`**: такой предмет **нельзя класть в слоты рюкзака** (нет «сумки в сумке»). В экипировку/в руки по-прежнему можно, если сервер не вводит доп. ограничений.

Если каталог на сервере **не** загружен, проверка `is_storage` **не** применяется (для dev).

## Константы в `pkg/gamekit`

- Тип сообщения: **`TypeInventoryMove`** = `"inventory_move"`.
- Структура payload: **`InventoryMoveIntent`** (`from`, `to`).
- Имена слотов: **`InvSlotArmor`**, **`InvSlotAccessory1`**, … **`InvSlotBackpackPref`** + индекс.

## Регрессия

- Старый **`character.data`** без `inventory`: после разбора подставляется **пустой** инвентарь.
- Старый **снимок мира** без компонента инвентаря: при загрузке мира игрокам добавляется **пустой** инвентарь.
