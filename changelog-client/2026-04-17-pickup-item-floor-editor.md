# Клиент: подбор с пола (`pickup_item`) и расстановка предметов в редакторе

## Быстрый тест в клиенте

В репозитории в **`game-service/data/content/catalog.json`** уже заведён предмет **`floor_gem`** (`pickable: true`, без `interact`). Через редактор отправь **`spawn_tile`** с **`texture": "floor_gem"`** на клетку, подойди вплотную (Чебышёв ≤ 1), затем **`pickup_item`** с **`item_def_id": "floor_gem"`** и **`click_x` / `click_y`** на эту клетку — камень должен исчезнуть с пола и появиться в первом свободном слоте рюкзака в **`state.players[].inventory.backpack`**.

## Подбор (`pickup_item`)

Новый тип сообщения WS (как у остальных, `service: "game"`):

- **`type`: `"pickup_item"`**
- **Payload** — объект **`PickupIntent`**, по полям как у **`InteractIntent`**:
  - **`item_def_id`** — id из `catalog.json` (должен совпадать с **`texture`** тайла на земле).
  - **`click_x`**, **`click_y`** — обязательны (целые координаты клетки).
  - **`click_layer`** — опционально; если нет / `null`, берётся тайл с **максимальным** `layer` среди совпадений (как при `interact`).

Условия на сервере (иначе действие **тихо игнорируется**):

1. В каталоге есть предмет с этим **`item_def_id`** и **`pickable": true`**.
2. В указанной клетке есть тайл с **`texture` == `item_def_id`**.
3. Игрок стоит в **соседней клетке по Чебышёву** (включая диагональ и ту же клетку): `max(|dx|,|dy|) ≤ 1` между позицией игрока и `(click_x, click_y)`.
4. В рюкзаке есть **свободный** слот (`backpack_0`…`backpack_4` с пустой строкой). Если места нет — предмет **остаётся** на земле.

При успехе: тайл на этом слое **удаляется** (в `state` уходит **`tile_updates`** с **`remove`**), в первый свободный слот рюкзака записывается **`item_def_id`**.

## Взаимодействие (`interact`) без изменений

**`interact`** по-прежнему только запускает сценарий каталога; **не** подбирает предмет. У предмета на земле могут быть и **`pickable`**, и **`interact`** — клиент решает, что отправить.

## Редактор мира: как «положить предмет на землю»

Договорённость та же, что для любого тайла: **`type: "spawn_tile"`** с **`texture`** = **`id`** предмета из каталога (например `"floor_gem"`). В каталоге у этого id выставьте **`"pickable": true`**, если игрок должен иметь возможность подобрать.

Пример записи в **`catalog.json`**:

```json
"floor_gem": {
  "id": "floor_gem",
  "name": "Gem (pickable)",
  "pickable": true
}
```

Опционально добавьте **`interact`**, если нужен сценарий при клике «взаимодействовать», отдельно от подбора.

## Константы в `pkg/gamekit`

- **`TypePickupItem`** = `"pickup_item"`.
- **`PickupIntent`** — структура payload (см. `wire.go`).
